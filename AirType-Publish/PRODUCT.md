# AirType

**一句话机制：** 一部"本地说出即键入"的端子——在手机上说话，文字落进电脑光标处；无服务器、无账号、同一局域网。

**受众与场景：** 坐在电脑前打字的开发者 / 写作者 / 办公者，想用手机语音喂字而不换手、不接线、不碰云。他们在工作节奏里，信任本机与隐私。

**文化归属：** 终端 / CLI / 遥测仪器 / 测量设备。这部工具本质是一台**键盘发射器**与一台**文字接收机**，像 KVM 与链路监视仪的组合。

**首个界面要证明的：** 这条"直连线路"可靠、安静、可信任——配对像"校准"，发送像"向链路写信"，状态像"信号灯"。

**产品约束（可长期承诺）：**
- 纯局域网、无账号、语音不出手机；UI 不夸大、不虚构网络行为。
- 双端同世界：PC 端=接收台，手机端=发射台，视觉与术语一致。
- 配对码只显示在 PC 屏幕、只输入手机，不经网络明文传输（v2 挑战-应答）。
- 克制的运动：一次、有物理直觉；深色终端世界为默认，不做反色凑数。

**非目标 / 反参考：**
- 不做"营销落地页式"的浅色 SaaS 卡片风、不做毛玻璃拟态、不用 emoji 充当图标。
