# AirType 设计文档（新版本 v1.0）

> 以老版 Phmic（phmic-1）为基线，保留其**同局域网语音上屏**核心价值与 **v2 安全协议**，
> 重做两端 UI 为现代高质感设计，并在手机端引入 `kuikly-ui-framework` skill 的声明式 DSL 风格。

## 1. 产品定义

- **名称**：AirType（手机语音/文字 → 电脑光标上屏）
- **核心流程**：手机输入框用手机自有语音输入法说话 → 点"发送" → 局域网 TCP → 电脑把文本"打"到当前焦点窗口的光标处。
- **语音识别位置**：手机系统输入法，本项目不集成任何语音 SDK。

## 2. 用户流程

1. 电脑端 AirTypePC 启动（托盘常驻），界面顶部大卡片醒目显示电脑名与 4 位配对码（码只显示在屏幕、不进网络）；每 1 秒广播 UDP 发现包。
2. 手机打开 AirTypePhone：自动列出发现的电脑（名字 + IP）；也可"扫描局域网/热点"兜底，或手动输入 IP + 配对码。
3. 点选电脑后输入配对码 → 挑战-应答认证（SHA-256），成功进入"已连接工作页"。
4. 在输入框语音/打字 → 点"发送到电脑" → 文字上屏到电脑光标处。
5. 断线自动重连（3s，本地存码静默完成挑战-应答）；最近 5 条可点击重发。

## 3. 网络与安全

- **电脑永远是 TCP 服务端**，监听 `0.0.0.0:47555`；手机为客户端，UDP 广播发现（端口 47556）。
- 同 WiFi 与手机热点两种拓扑天然都通。
- 仅局域网、无公网服务器、无账号、语音不出手机。
- **配对码不通过网络明文传输**：beacon 不含码；手机连接后电脑下发随机 nonce，手机回 `SHA-256(码+nonce)`，抓包无法还原码、无法重放。
- 本协议不加密（无 TLS），明示仅用于可信网络；目标程序以管理员运行导致粘贴失败时，请以管理员身份运行 AirTypePC。

## 4. 电脑端（WPF / .NET 8）

### 技术与视觉

- WPF 无边框现代窗口（`WindowChrome` + 自定义标题栏），**终端仪器** 世界：近黑机体 `#0B0E14` + 分层暗面板 + 发丝线，无投影。
- 品牌色：信号绿 `#5EE07A`（唯一强调）、绿调灰阶文本（`#D8EAE0`/`#86AE94`/`#52705F`）、发丝线 `#1E2633`；琥珀 `#FFB443`、信号红 `#FF6B6B` 为弱/错误态。

### 功能

1. **主界面**：顶部品牌栏 + 状态灯；终端面板内为**读数井**——信号绿大号等宽配对码 + 闪烁块光标、重新生成、断开配对；已配对设备列表；链路信息（IP/PORT/MODE）；运行日志（位于设置）。
2. **上屏**：`Paster` —— 剪贴板粘贴（默认，自动恢复原内容）或逐字键入（不碰剪贴板）。
3. **设置窗口**：电脑显示名、上屏方式、关闭最小化到托盘。
4. **托盘**：常驻、双击恢复、右键设置/退出；关闭窗口默认最小化到托盘。
5. **服务**：`Server`（v2 挑战-应答、心跳清理）、`Beacon`（含实例 ID）、`NetUtil`（多网卡 IP / 广播地址）。
6. **自检**：`--selftest` 全协议 PASS；`--uicheck` 验证 UI 构建。

## 5. 手机端（Kotlin + Kuikly 风格声明式 DSL）

### UI 设计系统

- 近黑画布 + 分层暗面板/暗井，信号绿文字与状态灯、发丝分隔线（与电脑端同一品牌语言：等宽读数、无投影）。
- 组件体系：`Column`（垂直流）、`Row`（水平流）、`Text`、`Button`、`Input`、`Card`、`Dot`、`Divider`、`Scroll`。
- 属性/事件聚合在单一 Scope：`bg / gradient / radius / pad / margin / elevation / weight / textSize / textColor / bold / click / inputType …`。
- 响应式：`State`/`observable`（与 skill 的 `observable` 同构，变量 set 触发订阅刷新局部区域）。

### 页面

1. **发现页**：终端状态行（LINK ● TRANSMITTER）+ 发射台面板（连接状态 + 信号绿强调条）+ 已发现电脑列表（发丝分隔，点击 → 配对码）+ 扫描 + 手动连接卡片。
2. **已连接工作页**：连接状态卡片 + 断开入口 + 输入大卡片（多行输入 + 信号绿发送按钮）+ 最近发送列表（点击重发）。

### 模块

- `TcpLinker`：连接、v2 挑战-应答、按行收发、心跳、3s 自动重连、码错误停止重连。
- `Discovery`：UDP 监听 beacon，实时列表。
- `SubnetScanner`：热点/隔离网络兜底 TCP 探测。
- `Auth`：SHA-256 十六进制。

## 6. 兼容与迁移

- 协议与老版 Phmic **v2 完全互通**，可跨版本联调。
- 手机端 DSL 采用 kuikly-ui-framework skill 语义，后续可翻译为真实 Kuikly `@Page` 代码迁移至 Kuikly SDK。
